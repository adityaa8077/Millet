# 🌾 Millet Marg — 3D Interactive Web Experience

> **The Golden Path from Conventional Wheat to Ancient Supergrain Dining**  
> An immersive WebGL 3D gastronomic journey showcasing the health, ecological, and culinary revolution of replacing industrial wheat with fire-forged ancient millets.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone)

---

## ✨ Key Features

1. **Netflix-Style Dynamic Navbar**:
   - Signature dark translucent-to-solid gradient transition on scroll.
   - Expandable interactive search bar for grains and dishes.
   - Interactive notification center & profile drawer with real-time cart tracking.
   - Smooth mobile slide-out navigation drawer with touch gestures.

2. **Real-Time 3D Grain Inspector (Three.js WebGL)**:
   - 360° touch and mouse-interactive 3D procedural grain models.
   - Switch effortlessly between **Conventional Wheat (Triticum)** and 4 ancient millets:
     - **Foxtail Millet (Kangni)** — Diabetic Gold Standard
     - **Pearl Millet (Bajra)** — Iron Fortress
     - **Finger Millet (Ragi)** — 10x Calcium Champion
     - **Little Millet (Samai)** — Ayurvedic Digestif
   - Live interactive gauges comparing Glycemic Index, Fiber, Protein, and Calcium.

3. **"The Marg" — The 4-Stage Wheat-to-Millet Journey**:
   - **Phase 1: Soil & Heritage** — Drought tolerance vs wheat monoculture water waste.
   - **Phase 2: Milling & De-Husking** — Whole bran retention vs bleached wheat flour (Maida).
   - **Phase 3: Fire Alchemy** — High flame wok flambé seared cooking.
   - **Phase 4: The Signature Plate** — Royal Foxtail Millet Bowl & slow-simmered Chana Masala.

4. **Authentic Kitchen Flame Video Reel**:
   - Curated high-definition footage of authentic chef wok tosses, sizzlers, spice infusions, and plating.
   - Auto-preview on hover with full-screen Cinema Modal playback and chef tasting notes.

5. **Wheat vs Millet Metabolic Substitution Lab**:
   - Interactive matrix simulating the replacement of wheat phulkas, suji upma, dalia, and pasta with millet alternatives.
   - Live calculations for glycemic reduction, satiety expansion, and liters of groundwater saved.

6. **Web Audio Flame Ambiance**:
   - Procedural hearth and flame synthesizer via Web Audio API.

## 🚀 Instant Vercel Deployment

### Option 1: GitHub & Vercel Dashboard (Zero Config)
1. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Millet Marg 3D Website"
   git branch -M main
   git remote add origin https://github.com/<your-username>/millet-marg.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) -> **Add New Project** -> Import your repository.
3. Keep default settings (Framework preset: `Other` or `None`).
4. Click **Deploy**!

### Option 2: Vercel CLI
```bash
npm install -g vercel
vercel
```

## 💻 Running Locally

### Using Python:

